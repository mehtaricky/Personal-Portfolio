# Personal Portfolio Website

A simple, responsive personal portfolio website created as part of the.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Flexbox and CSS Grid

## Features

- Personal introduction
- About Me section
- Education section
- Skills section
- Projects section
- Contact section
- GitHub and LinkedIn profile links
- Responsive design for mobile and desktop
- Dark / Light mode
- Interactive greeting based on user input
- Interactive contact form
- Modern cards, buttons, spacing, borders, and typography

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No additional installation is required.

## GitHub Pages Deployment

1. Create a GitHub repository named `personal-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/root` folder.
7. Save the settings.
8. GitHub will provide a live website link after deployment.
